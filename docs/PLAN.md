# خطة بناء واجهة SKYEYE — 7 جلسات

**المبدأ:** كل جلسة تسلّم الكود للتي بعدها عبر Git، وتنتهي بتحديث `docs/HANDOFF.md`. لا شيء يُرسل خارج الشركة دون موافقة بشرية.
**التقنية:** Next.js (App Router) + TypeScript + Supabase (Auth + RLS + Realtime). الأنماط CSS variables لتسهيل هوية مستقلة لكل شركة.
**قواعد ثابتة:** عربي RTL، الأكواد والأوقات UTC بالإنجليزية، لا جداول تقليدية، لا أرقام مخترعة، لوجو شركة المناولة وشركة الطيران حيث يظهر اسمها، وضع الظل ظاهر دائماً.

| # | اسم الجلسة | التسليم |
|---|---|---|
| 1 ✅ | **الأساس والهوية** | مشروع Next.js، نظام التصميم، الخلفية، الهيكل (قائمة وشريط علوي)، شاشة «قيادتي» بعقد بيانات |
| 2 ✅ | **الدخول وعزل الشركات** | تسجيل دخول Supabase، ربط المستخدم بشركة واحدة، RLS، نطاق فرعي ولوجو لكل شركة، استبدال بيانات المثال بالحقيقية |
| 3 ✅ | **الوارد والمسودات** | الإيميل بأربع نقاط (نوعه، المطلوب، الرد، المسودة)، مراجعة المسودة وإرسالها يدوياً بالإنجليزية |
| 4 | **ملفات الطلبات والتنبيهات** | ملف لكل طلب بمراحله، إغلاقه بدليل من الإيميل، تنبيه قبل الموعد بيوم، وتنبيه الراكد |
| 5 | **الرحلات ودورة المناولة** | قائمة الرحلات، الخط الزمني الحي، أسئلة المتابعة، زر Actions بقائمة الرسائل كاملة |
| 6 | **تقرير الوردية والتسليم** | تقرير آلي قبل التسليم بـ 15 دقيقة، الاستلام الصريح، متابعة الحالات المفتوحة |
| 7 | **محادثة الوكيل ولوحة الأدمن** | شاشة تواصل مع الوكيل، المستخدمون والورديات والصلاحيات، تقرير وضع الظل |
